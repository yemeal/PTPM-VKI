## Пункт В. Локализация аномалий

| Название теста                                               | Номер строки в `delivery.py` | Описание дефекта                                                                                                                                                                                                                     | Вариант исправления                                |
|:-------------------------------------------------------------|:----------------------------:|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:---------------------------------------------------|
| `test_express_delivery_must_be_more_expensive_than_standard` |              41              | Применяется операция `total_cost *= 0.5`, которая уменьшает итоговую стоимость в 2 раза (скидка 50%) вместо надбавки за срочность. Экспресс-доставка становится дешевле стандартной.                                                 | `total_cost *= 1.5`                                |
| `test_delivery_date_ceil_rounding_for_fractional_days`       |              46              | Использовано целочисленное деление `distance // 500`, округляющее значение вниз (при 501 км нужно 2 дня, а код дает 1).                                                                                                              | `days_needed = max(1, math.ceil(distance / 500))`  |
| `test_express_delivery_must_not_be_zero_days`                |              49              | Срок экспресс-доставки вычисляется как `days_needed // 2` без ограничения снизу. При `days_needed = 1` результат равен `0`, из-за чего дата доставки совпадает с датой отправки. Минимальный срок доставки должен составлять 1 день. | `days_needed = max(1, math.ceil(days_needed / 2))` |
